# Support

Official developer: **Yannick Huchard** — [GitHub profile](https://github.com/yannickhuchard).

Use [this repository's issues](https://github.com/yannickhuchard/air-plugin/issues) for plugin installation questions, defects and requests for engine access or an approved distribution. Support is community best effort; no SLA or response time is promised.

Include the plugin version, client/version, operating system, expected behavior and a minimal synthetic reproduction. Do not include tokens, credentials, private tunnel URLs, enterprise dossiers or personal data. For a sensitive security issue, request a private channel without publishing exploit details or confidential content.

The public plugin package and the privately distributed AIR engine have different access requirements. An unavailable engine repository is not resolved by changing the plugin's permissions. Official-directory submission and approval status are tracked separately in [submission/README.md](submission/README.md).
